# Tiny Party Club

Six two-player browser games with no accounts or backend. Each game uses a 4-character room code and PeerJS/WebRTC.

- `drop-four/` — Berry Four: head-to-head strategy
- `dodgeball-arena/` — Puffball Toss: head-to-head reflexes
- `lily-leap/` — Lily Leap: cooperative lane planning
- `honey-helpers/` — Honey Flight: cooperative flower-pattern rhythm
- `kitten-cleanup/` — Kitten Cleanup: cooperative reaction game
- `penguin-parcel/` — Penguin Delivery: cooperative routing puzzle

Run locally with `python3 -m http.server 8080` and open the site in two browser windows or devices.
